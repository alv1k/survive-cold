# About: tiin-app

A React Native mobile application project (TiinApp) related to the Hiddify/TIIN VPN ecosystem. Includes planning documentation and scaffolding for a Redux + NativeWind-based React Native app.

- **Language:** TypeScript
- **Framework/Libraries:** React Native, Expo (EAS config), Redux (planned), NativeWind/Tailwind, PostCSS
- **Platform:** iOS, Android (via EAS Build)
- **Features:**
  - Expo Application Services (EAS) configuration
  - NativeWind (Tailwind for React Native) setup
  - PostCSS configuration
  - Detailed architecture planning documentation (about.txt in Russian)
- **Package Manager:** npm/yarn
- **How to Run:** `expo start`, `eas build` for production
- **Deployment:** EAS Build
